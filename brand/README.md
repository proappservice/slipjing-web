## กติกาการใช้ (สรุปจาก CLAUDE.md)

- โลโก้คือริบบิ้นเครื่องหมายถูก **ไม่มีตัวอักษรในสัญลักษณ์** — ห้ามดัดแปลงเป็นแบบอื่น
- Wordmark: "Slip" (navy) + "Jing" (blue) **ติดกันไม่มีช่องว่าง** น้ำหนัก bold
- บนพื้นเข้ม: แขนสั้น sky `#6D9BE8` + แขนยาวขาว (ตามไฟล์ `-ondark` / `-navy`)
- เว้นพื้นที่ว่างรอบโลโก้อย่างน้อย ~25% ของความกว้างโลโก้ (ไฟล์ avatar เผื่อให้แล้ว)

## สร้างไฟล์ใหม่/แก้ขนาด

ไฟล์ PNG ทั้งหมด generate จาก SVG ในโฟลเดอร์นี้ — ถ้าต้องการขนาดอื่น เปิด SVG ในเบราว์เซอร์
แล้ว export หรือใช้ sharp/Figma ได้เลย (ต้นทางเวกเตอร์ ขยายเท่าไหร่ก็คม)
